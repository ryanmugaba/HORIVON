# HORIVON

HORIVON is a starter Next.js + Tailwind web app for an Australian small business financial copilot and economic radar.

## Features

- Landing page with marketing messaging and pricing
- Login/sign-up page
- Dashboard with Radar, Copilot, and Settings tabs
- Legal disclaimer page
- Recharts-powered charts and interactive UI
- GitHub Codespace-friendly devcontainer

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the app.
